# LibreRoute 1.2.32

Исправлено медленное восстановление прав владельца через SSH. Служебная сборка передаётся одним потоком вместо отдельных SSH-соединений для каждого блока 8 КБ. После обрыва проверяется сохранённая часть файла и передача продолжается с неё; целый файл проверяется по SHA-256 перед использованием.

Продолжение прерванного восстановления использует исходный запрос владельца и сценарий восстановления прав. Ошибка блокировки другой незавершённой операцией теперь содержит её идентификатор и стадию вместо пустого «SSH installer:».

Встроенное ядро — 1.2.44. Восстановление владельца сохраняет установленное ядро; его обновление остаётся отдельным действием.

Проверка: 8 сценариев потоковой передачи с реальными shell-скриптами в изолированных каталогах Linux, регрессии отката установки и 12 тестов состояния установки Android. Подпись APK совместима с предыдущими выпусками, данные сохраняются при обновлении приложения.
