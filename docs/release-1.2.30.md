# LibreRoute 1.2.30

Исправлена настройка сервера, на котором LibreRoute Core уже установлен.

- Найденное ядро больше не переустанавливается из-за отсутствия сохранённых прав
  или профиля администратора в приложении.
- Восстановление прав владельца отображается отдельно от установки и требует
  подтверждения. Установленное ядро и настройки сохраняются.
- При подключении к существующему серверу больше не запрашивается название нового
  профиля администратора. Управляемая установка определяется до проверки ядра.
- Обновление ядра остаётся отдельным действием.

Приложение из GitHub и LibreRoute Dev хранят права управления отдельно. При первом
подключении новой установки приложения к существующему серверу нужно принять
приглашение администратора или восстановить права владельца через SSH.

Включено Core 1.2.43. Android 8.0 и новее, ARM64. APK подписан прежним ключом:
его можно установить поверх версии из GitHub с сохранением данных.

Проверка: 15 тестов настройки сервера и состояния установки успешно пройдены.
Кодировка исходников и описания выпуска проверена.
