# Подпись Android-сборок LibreRoute

Документ описывает локальную процедуру без хранения ключей, паролей,
сертификатов и исторических хэшей.

- Debug: `:app:assembleDebug` для тестирования;
- Release: `:app:assembleRelease` с ключом, заданным локальной конфигурацией;
- Trial: отдельный вариант только при необходимости тестового пакета.

Файлы keystore не должны находиться в документации или исходном репозитории.
Перед выпуском проверьте package ID, versionCode, подпись и SHA-256 готового APK
в локальном release-чеклисте.
