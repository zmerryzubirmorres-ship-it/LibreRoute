# Администрирование: готовность сервера и прогресс настройки доступа

Дата: 2026-10-16.

## Что означало предупреждение

Раньше надпись «Готовность части серверов ещё не подтверждена» показывалась при
любом неподтверждённом состоянии снимка, включая единственный сервер. Количество
серверов не было причиной предупреждения. Зелёное состояние требовало полного
снимка, статуса рабочего процесса, подтверждённого применения конфигурации,
готовности маршрутов и отсутствия ошибки рабочего процесса.

Без свежего ответа конкретного сервера нельзя определить, какое именно условие
не выполнено. Предупреждение само по себе не доказывает недоступность сервера:
административный канал и готовность рабочих маршрутов — разные состояния.

Для одного сервера вместо общей надписи теперь показывается причина:

- сервер ещё не сообщил состояние рабочих маршрутов;
- сервер сообщил об ошибке рабочих маршрутов;
- сведения о сервере получены не полностью;
- сервер ещё не подтвердил применение конфигурации;
- готовность маршрутов сервера ещё не подтверждена.

Для нескольких серверов показывается количество подтверждённых из общего числа.
Пропущенный статус одного из узлов не считается подтверждением готовности.

## Кнопки в деталях пользователя

Общий обработчик раньше заменял подписи всех кнопок текущим этапом команды.
В карточке пользователя назначен единственный получатель прогресса —
«Настроить доступ». Кнопки «Приостановить доступ», «Удалить с сервера…» и другие
элементы действий блокируются с сохранением подписей. После завершения
восстанавливаются исходные подписи и доступность, включая ранее отключённые
элементы.

Блокировка охватывает всё состояние `SUBMITTING`, в том числе подключение и
промежутки между отдельными командами. Новые представления после перерисовки
карточки получают то же поведение. Закрытие и восстановление диалога не запускают
серверные команды сами по себе.

Изменение касается Android UI; обновление удалённого сервера не требуется.
Проверки используют синтетические состояния и не меняют пользователей на сервере.

  восстановление исходной доступности.
