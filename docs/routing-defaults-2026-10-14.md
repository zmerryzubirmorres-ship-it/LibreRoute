# Начальные правила разделения трафика

Набор `app/src/main/assets/routing-defaults.json` перенесён из правил Dev-версии на телефоне 2026-10-14 по запросу пользователя. Он содержит только переносимые правила: имена пакетов, домены, действия и ссылки на профиль zapret. Серверов, ключей, учётных данных, UID и портов в нём нет.

- Приложения: 91 правило прямого доступа, 7 через туннель, 9 через zapret с профилем «Стандартный».
- Сайты: 646 правил прямого доступа, включая зоны ru, рф и su.
- «Вне списков — через туннель» по умолчанию выключен: остальной трафик идёт напрямую.
- Пакеты с префиксом `ru.` получают прямой маршрут. Явные правила имеют приоритет; пакеты с общим UID следуют явному назначению этого UID. Список установленных пакетов обновляется при новом запуске соединения, интерфейс использует свой существующий инвентарь.
- Старое раздельное туннелирование на новой установке выключено: оно не должно исключать приложения из VPN до применения новых правил. Явно сохранённое значение старого переключателя сохраняется.

Начальные значения применяются при отсутствии сохранённого состояния соответствующего раздела. Сохранённые правила, отключённые разделы и пользовательское положение переключателя не заменяются при обновлении. Для старых сохранённых JSON без нового поля автоматические правила `ru.*` не включаются задним числом.

Правила приложений требуют Android 10 или новее. На Android 8–9 начальный раздел правил приложений отключён, правила сайтов и общий прямой маршрут доступны. Установка не запускает VPN автоматически: правила действуют при подключении к серверу либо включении автономного zapret.

Проверка: 21 тест (`RoutingDefaultsTest`, `AppRoutingTest`, `SiteRoutingTest`, `TrafficRoutingPresetsTest`) прошёл. Проверены валидность встроенного набора, формирование конфигурации Core с прямым маршрутом по умолчанию, приоритет явных назначений и общих UID, появление нового пакета `ru.*`, совместимость старых сохранённых состояний. Debug APK собран успешно. Пользовательские данные телефона не изменялись.
