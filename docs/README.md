# Документация Android

Актуальные продуктовые сценарии находятся в корневом каталоге `docs/`. Здесь
оставлены только документы, относящиеся к сборке и диагностике Android.

- `connection-diagnostics.md` — правила чтения фактического состояния туннеля;
- `release-signing.md` — локальная процедура подписи сборки.

Исторические сценарии экранов и старые отчёты удалены. Не добавляйте сюда
стендовые хэши, VDS-адреса или промежуточные результаты тестов.
