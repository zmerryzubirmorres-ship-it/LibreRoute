# LibreRoute 1.2.40

Последняя сборка Android с накопленными изменениями интерфейса и подключения.

- В администрировании сообщение о готовности учитывает количество серверов. Для единственного сервера указана конкретная причина: нет статуса, конфигурация ещё не применена или готовность маршрутов ещё не подтверждена.
- В деталях пользователя ход подключения и настройки отображается только на кнопке «Настроить доступ». Остальные кнопки сохраняют свои надписи и недоступны до завершения операции, включая промежутки между командами.
- Включены накопленные доработки главного экрана, локального SOCKS/HTTP-прокси, восстановления соединения и административных операций.

Подписанный APK для Android 8.0 и новее, arm64-v8a. Устанавливается поверх предыдущей release-версии с сохранением данных. Встроенное ядро — 1.2.50.

Проверки: 400 JVM-тестов; проверка состояний кнопок на эмуляторе Android; проверка подписи APK и соответствия встроенных артефактов ядра исходникам.
