# LibreRoute 1.2.36

Исправлена группа настроек прокси: раздача по LAN больше не закрывает соединение сразу после запуска передачи. SOCKS5 и HTTP CONNECT поддерживают обмен данными в обе стороны; обычные HTTP-запросы корректно преобразуются для конечного сервера, служебная авторизация прокси ему не передаётся.

Логин и пароль локального SOCKS5 теперь передаются Core в VPN-режиме и используются внутренней проверкой связи. Режим «только прокси» очищает несовместимые параметры TUN, ожидает готовность транспорта и корректно останавливается при отмене и переключении. Для него не запрашивается разрешение VPN; zapret продолжает использовать VPN-службу.

Настройки показывают фактическое состояние раздачи и адрес локального SOCKS5. Изменения авторизации применяются после переподключения; раздача с неподходящими учётными данными до этого отключается. Исправлено определение адреса в сетях 10/8 и 172.16/12, удалена подстановка несуществующего адреса точки доступа.

Объём и ограничения проверки: [проверка прокси](proxy-functional-audit-2026-10-14.md).

Встроенное Core: 1.2.44.
