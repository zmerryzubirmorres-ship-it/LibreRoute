# LibreRoute 1.2.29

- Настройки трафика для приложений и сайтов: через туннель, через zapret с выбранным профилем или напрямую.
- Профили zapret, преднастройка «Россия напрямую», цветовые группы и фильтры, общий переключатель маршрута вне списков.
- Подключение zapret без сервера также учитывает правила приложений и сайтов; назначения через туннель используют zapret.
- Универсальные группы каналов и доработки Jazz. Наличие реализации не означает завершённую приёмку ускорения на всех сетях.
- Обновление Core через SSH и доступные транспортные каналы, возобновление передачи и восстановление серверных протоколов.
- Сохранение состояния экранов при повороте, возврат кнопкой «Назад», сохранение списка приложений без повторного запроса PackageManager.
- Компактный WebView со строкой адреса, обновлением и остановкой загрузки. Термин «Пользователи» в администрировании.
- Встроенное ядро Core 1.2.43; установочные бинарники Linux amd64/arm64 и подписанные манифесты включены в APK.

Релизная сборка предназначена для Android 8.0 и новее, ARM64. Пакет `io.github.libreroute` подписан существующим релизным ключом. LibreRoute Dev устанавливается отдельно и использует другой пакет.

Проверки MQTT и Jitsi, а также дальнейшие сетевые замеры мультиканала отложены по решению пользователя. Этот выпуск не объявляет их завершёнными. Кодировка исходных текстов и описания релиза проверяется как UTF-8.
