# LibreRoute 1.2.35

Вкладки «Администрирование» приведены к единому оформлению.

- «Обзор»: сводка пользователей и серверов, быстрые переходы, добавление пользователя и сервера, отдельный выбор канала управления. Журнал и действия администратора находятся в раскрываемом разделе.
- «Пользователи»: поиск, фильтры статуса и карточки с назначенными серверами и протоколами. Основная кнопка — «Добавить пользователя»; повторная выдача ссылки и технические назначения доступны в «Дополнительно».
- «Серверы»: поиск по имени и адресу, фильтры «Все», «В сети», «Требуют внимания», карточки состояния и Core. SSH-ключ и технические списки перенесены в «Дополнительно».

На карточках серверов отображаются время последней проверки и количество назначенных пользователей без повторного подсчёта одного пользователя по разным протоколам. Удалена условная полоса CPU с постоянными 25%; вместо неё показаны реальные характеристики процессора. Данные памяти относятся к последнему опросу.

Выбранная вкладка, поиск, фильтры, раскрытые разделы и отдельная прокрутка каждой вкладки сохраняются при повороте. Переключение вкладок и фильтрация работают по загруженным данным. Кнопка «Назад» из вкладок возвращает в «Обзор».

Встроенное Core: 1.2.44.
