# LibreRoute 1.2.33

При открытии «Протоколы сервера» ссылки, восстановленные с сервера, теперь появляются в полях настройки. Раньше экран запоминал первоначальные пустые поля как черновики и скрывал загруженные значения.

Черновиками считаются только явные изменения полей. Они сохраняются при повороте, включая намеренное удаление ссылки. Для активного подключения используется сохранённый маршрут, а не адрес устаревшей попытки установки.

В журнал восстановления добавлен список типов полученных подключений без ссылок, ключей и токенов.

Dev и основное приложение используют отдельные хранилища и идентичности. Это исправление отображает доступные текущему устройству серверные подключения; оно не переносит локальные настройки Dev и не меняет привязку парных Jazz-подключений к устройству.

Встроенное Core: 1.2.44.
