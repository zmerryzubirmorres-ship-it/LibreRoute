# Сохранение экранов при повороте · 2026-10-14

## Исправления

Кнопка «Отменить подготовку» раньше определялась при построении экрана только по локальной стадии `planned`. Начало передачи меняло её на `submitting`; после пересоздания Activity кнопка исчезала. Доступность отмены теперь хранится в `ServerSetupViewModel` и учитывает подтверждённую стадию сервера. Передача допускает остановку, переключение ядра — нет. Запрос остановки сохраняется и не заменяется последующими сообщениями прогресса.

Через общий реестр `DialogScreens` восстанавливаются подтверждения восстановления владельца и обновления ядра, приостановки пользователя, отзыва назначения, удаления сервера, меню соединения, удаления соединения, ошибки подключения и запроса настройки батареи. Для добавления сайта сохраняются черновик, ошибка и положение ввода. Сохраняется меню уровня журнала.

WebView удерживается в ViewModel с перепривязкой контекста к новой Activity: сохраняются DOM, введённые поля, текущая страница и история. Контекст старой Activity освобождается при отсоединении, WebView уничтожается при завершении владельца ViewModel. Дополнительно сохраняются строка адреса, загрузка, ошибка страницы и кнопка повторения. Это гарантия для смены конфигурации; сохранение произвольного DOM после уничтожения процесса не обещается.

Исправлены потеря позиции при нескольких последовательных перестроениях страницы, сброс внутренней вкладки подключений и сообщения проверки параметров комнат Jazz.

## Границы проверки

Инвентаризированы все 22 Activity основного manifest, основные Fragment и диалоги. Android пересоздаёт экраны при повороте: запрет поворота и `configChanges` для обхода пересоздания не добавлялись.

Проверки выполняются на `emulator-5554`. Формы содержат вымышленные адреса и данные; администрирование использует отдельное хранилище в памяти с отключёнными серверными командами. Страницы браузерных проверок локальные. Проверки не меняют VDS89, не запускают VPN и не подтверждают работу реальных провайдеров. Интерфейс телефона автоматически не нажимается.

При проверке WebView сохранение полей и сессии проверяется именно при повороте; возврат на предыдущую страницу проверяется отдельно и может загрузить страницу заново по обычным правилам браузера.

## Отдельно об ошибке GitHub-версии

На телефоне обнаружена GitHub-версия 1.2.30. Её внутренний файл настройки нельзя прочитать через `run-as`: пакет не отладочный. Журнал старой Dev-версии не доказывает причину ошибки GitHub-версии.

Чтение серверного состояния показало незавершённую передачу сборки. Это не подтверждает повторную установку или переключение ядра. Операция не отменялась и не продолжалась этими проверками.

В 1.2.31 журнал настройки включён в экспорт журнала, а новые очищенные от секретов события доступны в logcat с тегом `LibreRouteSetup`. Для установления причины исходной ошибки нужны события именно GitHub-пакета после воспроизведения либо экспорт сохранённого журнала.

Отдельно в старом журнале Dev найден аварийный выход при сетевой ошибке `Ipv4WebViewProxy`. Ошибки отдельного CONNECT-запроса теперь возвращаются браузеру, не завершая приложение; локальный регрессионный тест проверяет отказ соединения и следующую успешную передачу через тот же прокси.

Модульные проверки: 18 тестов, 0 ошибок (`ServerSetupLifecycleTest`, `ServerInstallationStateTest`, `Ipv4WebViewProxyTest`).
