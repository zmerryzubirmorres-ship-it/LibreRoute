# LibreRoute 1.2.34

Экран «Доступ пользователя» показывает понятную последовательность выдачи ссылки: выбор подключений, проверка их списка и «Создать ссылку». Серверы оформлены карточками; у каждого способа подключения есть пояснение. Поля ссылок появляются только у отмеченных способов, которым нужна отдельная комната или документ.

Список выбранных подключений и основная кнопка закреплены внизу. Повторяющаяся кнопка компактного QR удалена: после создания ссылки доступен общий экран отправки и QR-кода. Объединённые каналы и назначение по публичному ключу помещены в раскрываемый раздел «Дополнительно».

При отсутствии ссылки ошибка показывается у поля. Выбор серверов, протоколов, введённые ссылки и раскрытый раздел сохраняются при повороте. Для ручного Jazz перед созданием приглашения проверяется введённая ссылка; автоматическая выдача используется только для маршрута с подтверждённым автоматическим распределением комнаты.

Встроенное Core: 1.2.44.
