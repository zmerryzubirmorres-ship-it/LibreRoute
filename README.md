## Преимущества форка

### 🔒 Продвинутая безопасность и маскировка
* **Сквозное AES-256-GCM шифрование:** Провайдер промежуточного сервиса видит только нечитаемый шум. Каждое направление (клиент → сервер и сервер → клиент) использует независимый производный ключ (`scrypt` + `HMAC-SHA256`).
* **Защита от атак повтора (Anti-Replay):** Уникальные 12-байтные nonces и скользящее окно недавних пакетов для предотвращения replay-атак.
* **Изолированное хранение ключей и приватность:** Гарантированное удаление ключевых файлов с диска при сбросе настроек, защита от утечки секретов через строковые дампы и полная очистка системных логов от чувствительных данных.

### 🌐 Сеть и DNS
* **Интегрированный DoT-клиент и DNS-кэшер:** Решает многолетнюю проблему на современных Android (включая Android 14/15/16), маршрутизируя DNS-запросы через зашифрованный TLS (порт 853) к доверенным резолверам (Google, Cloudflare, Yandex) и локальный кэш `pdnsd`.
* **Выбор DNS-провайдера:** Поддержка DNS over HTTPS (DoH), DNS over TLS (DoT), системного DNS сети или ручной установки серверов.
* **Настройка MTU:** Тонкая подстройка MTU (1280–1500) с готовыми пресетами под сотовые вышки и IPv6 для стабильной работы без фрагментации пакетов (дефолт 1400).
* **Kill Switch:** Мгновенная блокировка трафика в обход туннеля при непредвиденном разрыве соединения.

### 🎯 Раздельное туннелирование (Split Tunneling)
* **По приложениям:** Выбирайте, какие приложения пускать через туннель, а какие оставлять в прямой сети («Обход» или «Проксировать»), с удобным поиском по списку.
* **По доменам и сервисам:** Встроенные и пополняемые базы пресетов в один клик:
  * Российские сервисы (.ru, .рф, Госуслуги, банки, маркетплейсы — прямой доступ без VPN);
  * YouTube и Google Video;
  * Discord и голосовые каналы;
  * AI-сервисы (ChatGPT, Claude, Copilot, Midjourney);
  * Заблокированные ресурсы (АнтиЗапрет, Instagram, Twitter/X).

### 📡 Раздача интернета
* **Превратите телефон в шлюз:** Автоматический запуск моста при подключении VPN для раздачи защищенного трафика на ноутбук, консоль или ТВ по Wi-Fi.
* **Бесшовное подключение:** Локальный порт SOCKS5 изолирован от внешнего LAN-порта (10808) во избежание конфликтов портов, а авторизация в локальной сети по умолчанию отключена, устраняя ошибки HTTP 407 на подключенных устройствах (с поддержкой RFC 1929 при необходимости).

### 🛠 Мониторинг и интерфейс
* **Информация о подключении:** Реальный замер сквозной задержки (ping) и скорость приема/отдачи прямо в постоянном уведомлении и на главном экране.
* **Журнал событий:** Кольцевой буфер до 1000 строк для фиксации событий раннего старта и экспорт логов с датой и временем (`fluxon_logs_yyyy-MM-dd_HH-mm-ss.txt`).
* **Импорт и экспорт без ограничений:** Распознавание QR-кодов прямо из скриншотов в галерее, экспорт настроек QR-изображением и поддержка ссылок `openflux://` и `fluxon://`.

## Установка

Публичные сборки этой версии пока не опубликованы. Не устанавливайте APK из
исходного проекта в ожидании нашего Go-ядра: это другая сборка. Источник
обновлений — будущие GitHub Releases репозитория
`zmerryzubirmorres-ship-it/LibreRoute` (задаётся свойством
`openfluxUpdateRepository` в `gradle.properties`). Приложение показывает
доступный релиз и открывает страницу загрузки APK в браузере — автоматическая
установка не реализована.

В этом репозитории находится только Android-клиент. Изменённое Go-ядро OpenFlux
и скомпилированный `libopenflux_client.so` здесь не опубликованы. Поэтому APK,
собранный без отдельной сборки ядра, не является рабочим клиентом. Публикация
APK отложена до доступности соответствующих исходников Go-ядра и постоянного
ключа подписи релизов.

Требуется Android 8.0 (API 26) или выше.
В текущей локальной сборке нового ядра поддерживается `arm64-v8a`.
Старые готовые библиотеки других ABI оставлены в исходном репозитории, но в
APK этого варианта не включаются.

## Сборка

Локальные изменения статуса подключения и ограничения нативного ядра описаны
в [документации диагностики](docs/connection-diagnostics.md).

Сначала соберите Go-ядро из соседнего каталога `OpenFlux` (Go 1.26.8) через
Android NDK с CGO, затем Android-приложение. NDK нужен в том числе для системного
DNS-резолвера Android: чистая Go-сборка без CGO не разрешает имена сервисов в
этом процессе. На Windows:

```powershell
.\build-openflux-core.ps1 -GoExe 'C:\path\to\go.exe'
.\gradlew.bat assembleDebug
```

Для этой локальной сборки установлен Android SDK Build Tools 36.0.0. Скрипт
создаёт `app/src/main/jniLibs/arm64-v8a/libopenflux_client.so`; старый
`libp1npplydtransport.so` он не перезаписывает, но исключает из нового APK.
Без нового файла APK не должен считаться готовым клиентом. Нужны JDK 21,
Android SDK Platform 34, Build Tools 36.0.0 и Android NDK (скрипт выбирает самую
новую версию в `$ANDROID_SDK_ROOT\ndk`; путь можно передать параметром
`-NdkRoot`). Проверенная локальная сборка выполнена NDK 30.0.16248370.

Debug-вариант имеет отдельный идентификатор приложения с суффиксом `.dev`,
отображается как «LibreRoute Dev» и устанавливается рядом с существующим Fluxon
без замены его данных.
Готовый тестовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

24.09.2026 в debug-сборке добавлена ручная проверка CAPTCHA Яндекса через
WebView. После её прохождения cookies хранятся в приватном файле приложения и
используются Go-ядром при повторном подключении. В тесте `Test` авторизация
и WebSocket прошли, но сквозная HTTPS-проба пока завершается тайм-аутом;
показываемый статус «Нет сквозной связи» остаётся правильным.

Исходный Android-клиент теперь использует TUN через `VpnService`, наш Go-процесс
и локальный SOCKS5 для сквозной пробы. Перечень пока не перенесённых функций —
в [документации диагностики](docs/connection-diagnostics.md).
